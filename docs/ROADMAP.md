# Flute Builder Studio Roadmap

## Vision

Flute Builder Studio (FBS) is an open-source application for designing, building, measuring and documenting bamboo flutes.

Unlike traditional CAD software, FBS is intended to become a complete digital workshop for flute makers. It combines instrument design, acoustic calculations, workshop documentation and long-term knowledge management.

The project is designed to support both hobbyists and professional instrument makers.

---

## Supported Instruments

The long-term goal is to support:

* Bansuri
* Xiao
* Shakuhachi
* Hotchiku
* Quena
* Kaval
* Native American Flute
* Custom end-blown and transverse flutes

---

## Project Principles

* Open Source (MIT License)
* Cross-platform (Linux, Windows, macOS)
* Python + Qt (PySide6)
* Test-driven development where appropriate
* Real workshop measurements are preferred over theoretical assumptions
* AI can assist the design process, but every result should be validated by physical measurements
