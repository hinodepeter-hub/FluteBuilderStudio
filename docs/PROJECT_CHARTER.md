# Flute Builder Studio – Project Charter

## Mission

Flute Builder Studio is an open-source platform for designing, building, measuring, documenting and preserving the knowledge of traditional flute making.

The project combines acoustic calculations, practical workshop experience and documented measurements into a single application.

## Vision

To become the most comprehensive open-source software for bamboo flute makers.

## Core Values

* Open knowledge
* Measured results over assumptions
* Reproducible instrument designs
* Clean software architecture
* Long-term maintainability

## Guiding Principle

Every flute tells a story.

Flute Builder Studio should preserve that story—from the first design sketch to the finished instrument.
